Website Feed Privacy

Updated November 4, 2026

The Bald Dude Website Feed app connects The Bald Dude Co.’s own Instagram account to the Instagram section of thebalddude.co. It is used to display that account’s public posts, including photos, carousel posts and Reels shared to its main profile grid.

Information used

The feed uses the connected account’s profile identifier and media information: post identifiers, captions, image or video thumbnail URLs, post links, publication times and media types. Copies of public thumbnails and post information are stored with the website so visitors can see the feed.

Access and storage

The website feed requests read-only profile and media access. It does not need permission to publish posts, manage ads, read private messages or manage comments. The access token is kept outside public website files in restricted deployment credentials. Scheduled website jobs use it to retrieve updates.

The website is hosted using GitHub Pages and its feed updates run using GitHub Actions. Meta processes the connected account and authorization information under its own policies. Public feed copies remain available until refreshed or removed. Revoking access stops future authenticated updates; it does not automatically erase copies already displayed on the website.

Disconnecting and requesting deletion

The account owner can revoke the app’s access in the relevant Meta or Instagram account settings. To request removal of information stored for this website feed, email info@thebalddude.co with the subject “Website feed data removal” and identify the connected account or posts concerned. We will review the request, verify account ownership where necessary and remove the applicable feed data and credentials under our control.
