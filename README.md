# The Bald Dude Co. — Website

The production source for [thebalddude.co](https://thebalddude.co), the New York photography portfolio of Justin von Braun and The Bald Dude Co.

## Site

The current site is a responsive, single-page portfolio built with plain HTML, CSS, and JavaScript. It includes:

- A fast mixed-media hero sequence using original model photography and video
- Selected fashion and editorial work
- Motion reels
- About, services, and contact sections
- The Bald Dude Co. brand assets and `#ff004c` visual system

## Repository structure

```text
/
├── index.html
├── styles.css
├── script.js
├── assets/
│   ├── brand-*.png
│   ├── *.jpg
│   └── *.mp4
├── CNAME
├── LICENSE
└── README.md
```

The repository is configured for GitHub Pages with the custom domain `thebalddude.co`. All production media used by the page is stored locally in `assets/`; the site does not depend on remote image or video hosting.
